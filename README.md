# 映画棚（movie-shelf）

自分のスマホの中にある映画・ドラマのファイルを、木の棚のような箱に並べて管理するアプリです。
Web版「映画棚」で形が固まったものを、そのままスマホアプリにしたものです。

## できること

- 棚（箱）を無制限に作る：箱をタップするとその棚だけが開きます
- 作品の登録：端末内の動画ファイル（mp4 / mkv / mov / avi / webm）を選んで登録
  - 大きなファイルはアプリ内にコピーしません。ファイルの場所と情報だけを覚えます
- まとめて追加：複数のファイルを一度に選ぶと、ファイル名順に話数が自動で付きます
- つづきマーク：10秒以上観た作品には赤い「▶ つづき」が出て、棚の箱から直接その話を開けます
  - 最後まで観ると「観た」になり、つづきマークは次の話へ移ります
- 並び替え：棚の中でドラッグして順番を変えられます（保存した順番が話数順より優先）
- バックアップ：棚と作品の情報をJSONファイルに書き出し／読み込みできます
- 横向き対応：画面の向きは固定していません。横向きでも使えます

## ビルド（Codemagic）

このリポジトリには `codemagic.yaml` が入っているので、Codemagicにこのリポジトリを
アプリとして追加すれば、pushするたびに自動でAPKがビルドされます。

**ユーザーがやること（1回だけ）**

1. Codemagicにこのリポジトリ（movie-shelf）をアプリとして追加する
2. ビルドが終わったら、CodemagicからAPKをダウンロードする
3. スマホにインストールして実機で試す
4. 気になるところがあれば、その内容を伝える（直しはGitHub側のコードで対応します）

## v1の注意点（正直なところ）

- 作品の再生は、登録したときのファイルの場所（パス）を使います。
  スマホ側でファイルを移動・削除すると開けなくなります。その場合は作品の画面で
  「ファイルを選び直す」を押して、同じファイルを選び直してください（タイトルや
  つづきの位置はそのまま残ります）。
- 再生できない形式のファイルは、エラーの内容をそのまま画面に表示します。
- Web版に登録済みの作品データは自動では移りません。アプリ版で改めて登録してください
  （バックアップの書き出し／読み込みは、アプリ版同士での引っ越し用です）。
